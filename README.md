## greencloud iij 指的是什么

GreenCloud 的日本机房走 IIJ（日本互联网基础设施运营商）上游线路，从中国大陆方向去程电信、联通、移动基本都直连日本，回程电信和联通走 IIJ 直连，移动走 IIJ 或 Telstra。第三方评测中大陆方向多数在 40–80ms 区间，但个别批次联通回程经 Level3 转接时延迟会到 130ms 以上，所以具体延迟以你自己测到的为准。

东京机房是绿云所有机房里口碑排第一的（评测者普遍排序为东京 > 大阪 > 香港 DC01 > 新加坡 > 其它），促销款每次放出基本秒光。它抢手的原因就两条：价格低到离谱，线路对国内用户友好。

需要先打预防针的是：IIJ 是上游线路的统称，绿云日本机房的机器实际分到的路由可能因批次而不同，这一点后面细说。

## IIJ 和 Softbank 怎么选，回程到底走哪条

两条线路价格和硬件完全相同，差别只在回程路由，而这恰恰是最容易误判的地方。

**先说一个大多数测评文章没讲透的事实**：绿云日本机器的宣传线路和实际回程并不总是一致。2025 年周年庆闪购的那批“IIJ”套餐（AS3258 xTom Japan），有评测者 traceroute 后发现回程尤其回中国大陆方向实际走的是 Softbank（AS17676）。更早批次和大盘机的测试则显示三网均为 IIJ 直连。也就是说，你拿到的机器具体走哪条路，取决于批次和上游分配，宣传页写什么只当参考。

可靠的判断方法只有两个：

1. **下单前先测**。向商家索取目标机房当前的测试 IP（东京 IIJ 历史测试 IP 有 103.121.210.3、91.200.242.41 等几段），自己跑一下 traceroute 和 tcping，看三网回程和延迟。
2. **机器到手不满意再换**。绿云支持工单换 IP，$3 一次，可以顺便请求 43 开头的 IP 段（原因见下一节）。

对大多数大陆用户来说，IIJ 和 Softbank 两条线路的日常体验差距没有想象中大——两家评测给出的回程延迟都在 50–80ms 这个区间。真正需要纠结的场景是电信晚高峰：有大盘机评测认为电信走 IIJ 时表现相当糟糕，而另一些批次的双程 IIJ 测试中电信反而表现优秀。同一个关键词下结论打架，说明批次差异确实存在，别偷懒，测一下。👉 [对比东京 IIJ 与软银两条线路的在售套餐](https://greencloudvps.com/billing/aff.php?aff=6679)

## 下单前必须知道的几条限制

这部分是各家促销文章最常省略的内容，但每一条都直接影响使用。

**不退款。** 官网 Premium KVM 和 Storage KVM 两个系列每个套餐都明确标注 “No refund/money back on this plan”，不提供退款或退款保障。付款前确认好机房和配置，钱出去就回不来了。

**下单风控严格。** 需要使用真实信息下单，开代理下单会被砍单。这是老商家防滥用的常规操作，照做就行。

**用途限制。** TOS 明确禁止 DD Windows 和挖矿；不允许长时间占满 CPU 或带宽，持续跑满型用途会被限制；闪购批次没有 swap 分区。想拿它当长期满载下载机或算力机的可以省下这笔钱了。

**流媒体解锁看 IP 段运气。** 流媒体是动态封锁，商家不承诺解锁。网友实测经验：43 和 85 开头的 IP 段解锁 Netflix 概率较大，193 开头不行，172.93（IIJ 线路）不能解锁。不过 2026 年 7 月那批 Ryzen 7950X 机器实测 Netflix、TikTok、ChatGPT 日区原生解锁，说明新批次的 IP 质量在变好——前提是你分到的是那批。如果解锁对你重要，下单前先要测试 IP 确认，到手不对就花 $3 换 IP 碰运气，或者考虑绿云的新加坡机房（更多人选它解奈飞，新加坡区中文字幕也多）。

**流量是计费流量，不是不限量。** $25 档月流量 750GB，超了要付钱或停机。10Gbps 是端口规格，不代表能长期独享，实际速度受宿主机负载和拥塞影响。

**别指望拿它发邮件。** Ryzen 款实测 25 端口出站可用，但 Gmail、QQ 邮箱等主流方向的连通性检测不通，当主力发信机不合适。

## 哪些人适合买，哪些人可以划走

适合的场景很明确：个人建站（白天三网延迟低，访问流畅）、日常代理和轻量应用部署、需要日本 IP 但用量不大的场景。大盘机线则适合备份、归档、影音库这类大容量低 IOPS 的存储型需求，SATA RAID-10 的随机读写别抱期待。

不太适合的情况也直说：

- 需要 3TB 以上月流量又在乎价格的，绿云美国机房（盐湖城/纽约/芝加哥）同价位流量给到 3/6/10TB，是日本机房的三倍以上，只是回国线路差一大截。
- 持续高 CPU 或高带宽负载的业务，会被限制，别买。
- 需要原生 IPv4 或保证流媒体解锁的，这里只能碰运气，Ryzen 款也只是部分解锁。
- 要给邮件系统当主力服务器的，Gmail 方向不通，直接排除。
- 完全不能接受年付预付、不退款风险的，这家的模式天生不适合你。
